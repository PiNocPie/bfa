API keys and agents

You are responsible for what your agents do with your BFA API keys. Keep keys secret and revoke any key you think is exposed.

Top-ups carry a 1.5% fee added on top, split on-chain by a public contract. API calls are charged at the price shown in each listing; failed and empty calls are not charged unless the listing says otherwise.
