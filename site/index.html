Your agent pays per call. Its NEAR account signs.

For agents

One MCP server, seven tools, no EVM key

Add Nen to Claude Code or any MCP client. The only secret is a NEAR access key, kept in your environment. It asks the NEAR MPC network to sign, and never touches a Base private key.

.mcp.json
{
  "mcpServers": {
    "nen": {
      "command": "node",
      "args": ["/path/to/nen/packages/mcp-server/dist/index.js"],
      "env": {
        "NEAR_NETWORK": "testnet",
        "NEAR_ACCOUNT_ID": "<name>.testnet",
        "NEAR_PRIVATE_KEY": "${NEAR_PRIVATE_KEY}",
        "NEN_DAILY_CAP_USD": "1"
      }
    }
  }
}
  • discoverfreeFind reviewed APIs by query, with price and networks.
  • inspectfreeSchemas, example input, price line, review status and manifest hash.
  • quotefreeBest listing plus fallbacks: 45% success, 25% price, 20% latency, 10% billing.
  • runpaysValidates input, pays at most the listed price, returns data and a receipt.
  • receiptsfreeRecent receipts and today's spend against the cap.
  • walletfreeNEAR account, derived Base address, session key, USDC balance.
  • submit_listingfreeSeller dry run: schema check and an unpaid probe of the 402.

Errors come back as JSON with a code and a next_action (retry, use_fallback, fix_input, top_up, stop…), so the agent knows what to do next.

Receipts

One NEAR signature opens a channel, then calls take 200 ms

A Chain Signatures request takes seconds, which is too slow for every call. So the NEAR account signs one capped deposit into an x402 batch-settlement channel, and a local session key signs a voucher for each call after that.

Deposit, signed on NEAR

About 7 s through the MPC contract v1.signer-prod.testnet. Capped at $0.50 by default.

Each call, a voucher

Signed locally in 2–19 ms. The whole paid call takes about 200–300 ms.

Unused deposit comes back

The channel can be refunded. A failed call is never charged.

List your API

Open to anyone, routed after review

Listing is free and Nen takes no fee. Agents pay your address directly.

  1. Serve x402 V2Put any @x402 middleware in front of your endpoint.
  2. Write nen.jsonPrice, schemas, networks and data license, per the listing schema.
  3. Run the botsubmit_listing probes your 402 and lists anything to fix.
  4. Get reviewedA reviewer pins your manifest's sha256. Edits pause routing until re-review.
